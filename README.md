# Резюме — сайт для GitHub Pages

Три файла: `index.html`, `style.css`, `script.js`. Открываются и работают локально прямо двойным кликом по `index.html` — ничего собирать не нужно.

Перед публикацией: замените `mailto:you@example.com` в `index.html` (внизу, кнопка «Написать мне») на свой email или ссылку на Telegram.

Как опубликовать — см. основной ответ в чате.
